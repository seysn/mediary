# Mediary

Mediary is a set of libraries and tools for the processing of video content.

# Goals

The project has multiple goals ordered by importance :

1. Implementing as many multimedia codec as possible
2. Making clear code first, since this is is a personnal project aimed to learn these codecs
3. Then performance comes second, but if an algorithm is hard to read, keep an simpler equivalent aside
4. This project is not intended to go into production, because it is unlikely to achieve a sufficient level of maturity
